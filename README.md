# leeorlandi / testrepo

Here's an honest thing about how I work: I build constantly, and I share almost never.

There are folders on my machine full of half-finished things — tools, experiments, little systems I built to solve a problem and then kept tinkering with long after the problem was gone. None of them are "done." None of them have ever needed to be. That's sort of the point. The making is the thing.

GitHub, though, is a different habit. It assumes you're ready. It assumes there's something worth publishing. And I've been really, really bad at overcoming that assumption.

So I'm sprucing up this testrepo — not because it's impressive, but because leaving it as `yep. it is.` felt like a missed opportunity to at least be honest in public.

This is a placeholder. A breadcrumb. A small act of showing up.

---

**What's here:**
- An `index.html` that renders a terminal-style hello world — because if you're going to do nothing, you might as well make the nothing look good.
- This README — which now says something true instead of nothing useful.

**What's not here:** everything else I've built but never shared. That's a different project.

---

*Still tinkering. Rarely shipping. Working on it.*
